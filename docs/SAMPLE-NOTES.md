# 코드 예제 안내

이 저장소의 코드는 업무 처리 흐름을 별도로 구현한 예제입니다. 아래 추가 규칙은 예제에만 적용하였습니다.

| 기능 | 업무 구현 | 예제의 구성·추가 규칙 |
|---|---|---|
| 설정·답안 요청 | JSON 배열 해석, 내부 data에서 답안 추출 | 문자열 원소 제한, 필수 객체 검사, 읽기 전용 결과 |
| 캐시·DB 저장 | 캐시 반영 시도 후 DB 저장 | DB 오류를 호출자에게 전달. 두 저장소의 원자적 트랜잭션은 제공하지 않음 |
| 최근 로그 | 목록 앞쪽 추가, 최신 50개 보존, 선택적 만료 | 보존 개수와 만료시간을 인자로 전달 |
| 이벤트 처리 | 메시지 소비와 상태·답안·로그 저장 | EventProcessor의 이벤트 ID 저장소와 실패 큐 |
| 시험자료 반입 | ZIP 내부 JSON 추출과 시험자료 저장 | 경로 이탈 차단, 필수 JSON 존재 검사 |
| 인증·상태 이벤트 | 토큰·Redis 세션 확인, 응시자 이벤트 발행 | 분리된 인증 인터페이스와 이벤트 ID 중복 검사 |

DB·캐시·외부 시스템은 메모리 저장소 또는 주입 함수로 대체하였습니다. 테스트 결과는 이 예제에 해당합니다.
