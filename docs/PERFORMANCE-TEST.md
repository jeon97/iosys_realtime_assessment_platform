# 실시간 평가 부하 시험 시나리오

Spring Boot 전환 작업에서 JMeter·Scouter를 이용한 부하 시험과 서버 모니터링에 참여하였습니다. JMeter로 요청을 실행하고 Scouter에서 응답시간과 자원 사용량을 확인하였습니다.

## 시나리오 예제

이 저장소의 JMeter 파일은 실시간 평가의 HTTP 요청 흐름을 별도로 구성한 예제입니다. MSA 운영 환경의 실측 결과는 포함하지 않습니다.

| 요청 | 점검 항목 |
|---|---|
| 응시자 인증 | 토큰 발급·검증 응답 |
| 시험 진입 | 시험계획·응시자·문항 조회 |
| 답안 저장 | 요청 응답과 저장 경로 |
| 상태 변경 | 상태 이벤트 전달과 반영 |
| 운영 조회 | 응시자 상태 조회 응답 |

## 관측 항목

- JMeter: 요청 수·응답시간·오류율·처리량
- Scouter: 서비스별 응답시간·CPU·메모리·SQL 시간
- 메시지 처리: 큐 대기량과 워커 처리 상태
- 저장소: Redis·DB 호출시간과 오류
