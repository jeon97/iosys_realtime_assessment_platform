# 주요 처리 방식

## 상태 조회와 영속 저장

Redis에는 응시자의 최근 상태와 활동 목록을 반영하고 PostgreSQL에는 답안·로그를 저장하였습니다. 워커에서 캐시 반영 시도 후 DB 저장을 실행하도록 Reactor 체인을 구성하였습니다.

## 인증과 서비스 라우팅

인증 서비스에서 토큰 발급과 Redis 세션 상태를 관리하고 Gateway에서 인증 필터와 서비스 경로를 처리하였습니다. SSE 요청에 필요한 CORS와 응답 헤더를 설정하였습니다.

## 공통 모델 변경

시험계획·응시자·답안 모델과 Repository를 공통 모듈에서 관리하였습니다. 필드·식별자 타입·조회 조건을 변경할 때 사용하는 서비스의 공통 모듈 버전도 갱신하였습니다.
