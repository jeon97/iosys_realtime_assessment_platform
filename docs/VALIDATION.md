# 공개 예제 검증

2026-09-12 로컬 작업 사본에서 Java 테스트 **21개**가 통과하였습니다. 실패·오류·건너뜀은 없습니다. 신규 원본 기반 사례와 기존 예제를 함께 실행한 결과입니다.

## 실행

저장소 루트에서 실행합니다.

```sh
mvn -f samples/event-worker/pom.xml test
```


관리 UI 예제는 `node --test samples/manager-ui/examStore.test.mjs`로 실행하였으며 2개 테스트가 통과하였습니다.

## 확인한 범위

[신규 사례](CASE-STUDIES.md)의 정상 입력·경계·오류 흐름과 기존 예제 테스트를 확인하였습니다. DB·캐시·외부 호출은 예제의 메모리 구현 또는 주입한 함수로 대체하였습니다. 실제 회사 시스템의 통합 테스트, 부하 성능, 기관 SSO와 모델 서버 실행 결과가 아닙니다.

문서의 로컬 링크와 저장소 간 코드 경로를 현재 작업 사본에서 확인하고, 공개 대상 텍스트의 내부 주소·개인정보·인증정보 패턴을 검사하였습니다. 패턴 검사는 수동 검토를 보조하며 비식별화의 완전성을 보증하지 않습니다.
