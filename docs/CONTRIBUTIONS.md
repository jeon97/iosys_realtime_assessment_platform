# 담당 업무

## 공통 도메인 모듈

여러 서비스에서 사용하는 시험 관련 모델과 반응형 Repository를 관리하였습니다.

- 시험계획, 세션, 그룹, 응시자, 답안, 로그, 진행 상태 모델 추가 및 수정
- JSONB 컬럼 매핑과 식별자 타입 정리
- 서비스 요구사항에 맞춘 조회·삭제 메서드 추가
- 공통 모듈 버전 변경과 사용 서비스 의존성 업데이트

공통 모델 변경 시 사용하는 서비스의 의존성 버전도 함께 갱신하였습니다.

## 응시자 서비스

응시자가 시험에 접속한 이후 사용하는 주요 API와 상태 처리 흐름을 구현하였습니다.

- JWT 정보 기반 응시자·시험 데이터 조회
- 답안 조회와 저장, 시험 완료 상태 처리
- 시험 단계와 응시 진행 상태 갱신
- 접속 로그와 부정행위 의심 데이터 저장
- 채팅 메시지 발행 및 Redis 조회
- 모바일 카메라 상태와 이미지 업로드 처리
- RabbitMQ 발행 실패 시 저장 경로 처리

## 인증 서비스와 API Gateway

인증 서비스에서 토큰 발급과 세션 저장을 개발하였습니다. Gateway에서는 인증 필터와 서비스 라우팅을 구성하였습니다.

- Access Token과 Refresh Token 발급·검증
- Redis에서 사용자별 토큰 상태 확인
- 로그인 세션 정보 저장
- 인증 제외 경로와 역할별 접근 경로 설정
- Gateway JWT 필터와 동적 라우팅
- SSE 헤더와 CORS 경로 처리

## 이벤트 워커

응시자 서비스가 발행한 메시지를 실제 저장소에 반영하는 워커를 개발하였습니다.

- 답안, 상태, 로그, 채팅 메시지 소비
- Redis 실시간 상태 저장
- PostgreSQL 영속 저장
- 그룹·사용자 상태 데이터 구성
- 처리 순서와 조건 분기 정리

## 관리 서비스와 운영 화면

시험 데이터가 운영 시스템으로 들어오는 과정과 일부 운영 기능을 구현하였습니다.

- 시험계획·시험지·응시자 파일 동시 처리
- ZIP 파일 내부 JSON 추출과 저장
- 시험 데이터 동기화와 Redis 업로드·삭제
- 학생 답안 파일 다운로드
- 운영 화면의 시험 목록·상세 조회와 API 연동
